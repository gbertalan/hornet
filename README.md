# Project

## Project Design

This project follows the **MVC (Model-View-Controller)** pattern with an additional **Service layer** for business logic.

![Design overview](https://example.com/path-to-your-image.png)  
*(Replace the link above with your actual image URL)*

### Layers

- **Model**  
  Handles data and database interactions.

- **View**  
  Manages the user interface and presentation.

- **Controller**  
  Processes user input and coordinates Model and View.

- **Service**  
  Contains business logic and orchestrates operations between controllers and models.
